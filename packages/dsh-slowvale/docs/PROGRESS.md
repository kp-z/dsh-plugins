## 2026-11-21 00:20 · H4 完成（短信入口）

**这一小时做**：世界侧 Messenger（线程 + 回执 + tick 投递），43 个单测全绿。

**做了什么**：
- `runtime/messenger.ts`：
  - `receive(characterId, text, tick)` → 立刻回执（入队），不回模型；
  - `deliver(tick)` → 把排队消息交给角色当前的嘴，收下回复写回线程；
  - 线程挂在"玩家↔角色"上，**跨会话归档存活**；
  - 没有活会话时懒开一个（channel=personal），不轮换；
  - 某个角色忙时，他的消息留在队列，别人照常投递（不全局阻塞）。
- 6 个用例：回执、投递顺序、懒开只开一次、跨会话线程存活、忙时排队、非法输入。

**关键决策**：
- `receive` 与 `deliver` **分开**：这是"短信是异步的"的直接编码。前端拿到回执就走，
  回复由世界在下一个 tick 投递——这样"他在走路，过一会儿才回"不需要任何超时逻辑。
- 线程 id 就是 `thread:<角色id>`，把"线程属于谁"编码进 id，省掉一张映射表。

**卡点**：与 H3 相同——真模型未接入，回复文本目前来自脚本替身。

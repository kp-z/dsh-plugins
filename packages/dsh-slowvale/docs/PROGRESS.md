# PROGRESS

## 2026-11-21 02:20 · H6 完成（角色之间对话）

**这一小时做**：角色互聊过世界 + 防环（深度 / 每 tick 预算）；55 个单测全绿。

**做了什么**：
- `runtime/conversations.ts`：
  - `sayTo({fromId, toId, text, tick, hop})`：A 说 → 世界记 utterance → 投给 B 的会话 → 回复回世界；
  - 投递文本带说话人（`林野对你说：…`）——一个会话只有一个人，对方身份必须写进文本，否则 B 不知道在跟谁说话；
  - 防环两道闸：`maxHop`（默认 2）与 `maxPerTick`（默认 8）；
  - B 没有活会话时替他开一个，处境写"林野走过来跟你说话"；
  - `history()` / `utterancesOf(id)` 支持回放与诊断。

**关键决策**：
- 对话**必须**过世界，不能 A 直连 B 的会话：直连会绕过"谁在场、谁有话说、花了多少钱"，回放时也查不到"这句是回什么说的"。
- 防环是**规则**而不是提示词：模型不会自己停，这本来就是规则该裁决的事。
- 预算按 tick 计而不是按对话计：一句话的往返发生在同一个 tick 内，按 tick 才算得准。
- 不允许自己跟自己说话（会被当成两条独立消息，记录会乱）。

**卡点**：真模型仍未接入——"B 会不会顺着 A 的话说下去"目前只能靠替身验证链路，不能验证效果。

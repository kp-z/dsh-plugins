# NEXT · 下一步从哪开始

十小时做出了「世界的规则」，但有三件事**一次都没在真机上验过**。按顺序做，不要跳。

## N1 真机联调（最优先，半天）

目标：拿到一个能跑 \`sessionController\` 的宿主，把三个人真问一遍。

1. \`createDshPort(ctx)\` 已经写好，但**事件形状是抄来的、没验**（\`assistant/message\` + \`message.content[].text\`）。
   真机上先打一条日志，确认 \`session/event\` 的实际结构，不对就改 \`extractReply\`。
2. 给三个角色各开一个会话，同一个问题问三遍（例如「今天过得怎么样」），
   人工比对：像不像三个人。**不像就调 persona，不要先调 prompt 模板**。
3. 记录三份真实回复到 \`docs/REAL-RUN.md\`，作为"人设真的生效"的第一份证据。

## N2 挖三个契约（各半天到一天）

| 契约 | 怎么挖 | 挖到之后 |
| --- | --- | --- |
| HUD 聊天条目的信封形状 | SSE \`update\` 里 \`sceneStream\` 的 entry 真实字段 | 短信/对话才能推到左下角 |

| visual 帧内容与移动方式 | 抓真实服务端的 \`visual\` 包 | 决定"走路像不像走路" |

## N3 接世界的时钟

现在的世界没有 tick 驱动：短信投递、对话预算、日程都要靠 tick。
先把 100ms tick 与 \`Budget.forgetBefore\`、\`Messenger.deliver\` 接起来，再谈日程。

# Changelog

## 0.3.0

- 技能可设「何时使用」与调用方（两者 / 仅模型 / 仅用户）。
- 助手工具 `note_list` / `note_create` / `note_update` / `note_delete`；助手建的 MCP 便签一律未钉住。
- 导入 / 导出（先预览再确认，冲突可重命名 / 跳过 / 覆盖）；导入的 MCP 一律未钉住。
- 软删除：8 秒撤销，文件保留最近 50 条 / 30 天（数据文件升到 v3，v1 / v2 自动升级）。
- MCP 只在存在适用的活动会话时启动；不适用的会话看不到它的工具。
- 外观更简约：去掉噪点纹理、胶带、回形针，标签与图章压平，倾斜减半；文案精简。
- 键盘与无障碍：页签方向键、弹层焦点陷阱、纸条不再嵌套按钮、尊重「减少动效」。
- 修复：路由前缀 404；会话级技能挂不上；工作区作用域因取 cwd 失败被吞而悄悄失效；`note_delete` 的工具描述误称「永久」。
- 新增隔离的真实 DSH 测试实例（`scripts/e2e.sh`）与 4 组 e2e。

# xcity —— 小镇的工作区

这个目录是 **Agent World 的小镇（Slow Vale 前端 + 我们的后端）在 DSH 里的工作区**。

## 为什么单独开一个工作区

小镇里有几个人、每个人在哪个会话里说话，这些都属于"这个世界"的状态，
不该散落在随便哪个会话的目录里。放进工作区之后：

- 打开这个工作区，就能看到小镇里每个角色对应的会话；
- 绑定关系（谁代表谁）落在这里的 `bindings.json`，不随会话归档而丢；
- 会话可以换（归档旧的、开新的），**人和记忆不换**。

## 结构

```
xcity/
  README.md        这个文件
  bindings.json    角色 ↔ 会话 的绑定表（append-only，解绑只写归档时刻）
```

## 绑定规则（严格一对一）

1. 一个会话同时只能代表一个人；
2. 一个角色同时只有一个活会话——要换先归档。

这两条由 `dsh-slowvale` 的 `BindingTable` 强制执行（抛错，不是约定）。
